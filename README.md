Vegas sportsbooks employ sophisticated statistical models and decades of market data to produce betting lines that are remarkably accurate. This project explores whether modern tree-based machine learning algorithms can identify patterns beyond what is reflected in those lines and consistently predict NFL game outcomes against the spread and the over/under.

The project follows an end-to-end data science workflow, beginning with data collection and feature engineering, followed by exploratory data analysis, model development, hyperparameter tuning, and performance evaluation. Multiple tree-based models including Decision Trees, Random Forest, and XGBoost are trained and compared to determine which approach provides the strongest predictive performance. Model predictions are then evaluated against historical Vegas point spreads to assess whether they could have generated a profitable betting strategy.

Beyond predicting game outcomes, this project serves as a practical demonstration of applied machine learning, feature engineering, statistical analysis, and model evaluation using real-world sports data. The primary objective is not gambling, but rather understanding the predictive limits of machine learning in an efficient market and exploring how data-driven models can uncover meaningful insights from complex datasets.
